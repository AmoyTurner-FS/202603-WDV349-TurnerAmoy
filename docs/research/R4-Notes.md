## Topic - Front-End Development & Alpha Preparation

This document contains general notes related to preparing my application for the alpha stage, including component structure, file organization, styling approaches, and deployment basics.

<br>

## Sub-Topic 1 - Thinking in React (Components)
Breaking down the UI into reusable components helps organize development and makes the app easier to scale. Each part of the interface can be built and reused across multiple pages.

* Key finding 1: Components like sidebar, cards, and forms can be reused across pages
* Key finding 2: Props allow data to be passed between components
* Key finding 3: Default props and mock data can be used before connecting to an API

<br>

## Sub-Topic 2 - File Structure & Styling
Organizing files properly helps keep the project clean and easier to maintain. Styling should also be structured to avoid conflicts and improve scalability.

* Key finding 1: Separate folders for components, pages, and styles improves organization
* Key finding 2: CSS Modules or styled components help prevent styling conflicts
* Key finding 3: Keeping styling tied to components improves maintainability

<br>

## Sub-Topic 3 - Deployment & API Research
Understanding deployment and APIs is important for preparing the app for real world use. Even in early stages, planning for this helps future development.

* Key finding 1: Staging environments are used to test before production
* Key finding 2: Deployment platforms like Heroku can host applications
* Key finding 3: APIs like NHTSA can provide real vehicle data for the app
