## Topic - UI/UX and Production Planning

This document contains general notes related to improving the user experience, design decisions, and planning for development.


## Sub-Topic 1 - UI/UX



* Usability focuses on how easy and efficient the app is to use
* Learnability is important so users understand the app right away
* Reducing clutter helps improve efficiency and user experience
* Consistency across pages makes the app easier to use


## Sub-Topic 2 - Design Theory


* Visual hierarchy helps guide user attention
* Spacing and layout improve readability
* Avoiding too many elements prevents confusion
* Consistent design patterns make the app feel more professional


## Sub-Topic 3 - Production Planning



* Breaking the app into components helps with organization
* Planning models helps define the data structure
* State management controls how data flows through the app
* Routes define how users navigate through different pages
